# analyze_guidelines_for_llm -- 分析准则对大语言模型的适配性
$ARGUMENTS

## 任务说明
系统分析输入内容中所有以`-`开头的准则条目，评估每条准则的表述方式是否有利于大语言模型理解和执行。

## 分析维度
- **清晰度**：准则表述是否明确无歧义
- **避免高度抽象**: 使用尽量具体的描述，而不是高度抽象的表达，如果需要表达抽象的描述，将其分解为一个或者多个具体的表述
- **结构性**：是否具有规范的逻辑结构
- **可执行性**：是否包含具体的操作指引
- **一致性**：各准则之间是否存在冲突或重复

## 输出格式
对每条准则分别提供：
1. **评估结果**：有利/不利
2. **详细分析**：基于上述维度的具体分析
3. **优化建议**：如不利，提供具体的改写建议

## 优化原则
当准则不利于LLM识别时，参考以下原则改进：
1. **具体化**：将模糊表述转化为具体可操作的要求
2. **结构化**：使用统一的句式结构和逻辑顺序
3. **示例化**：为复杂准则补充具体示例
4. **标准化**：统一术语使用和表述规范
