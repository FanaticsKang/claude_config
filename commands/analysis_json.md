# JSON 数据链分析（Claude Command）

目标：
- 从 $ARGUMENTS 中拆解出目标 JSON 文件与需要分析的 JSONPath；
- 对工作区中的 JSON 数据进行链路分析与结构归纳；
- 给出读取该文件的 Python 程序架构建议；
- 最后向我确认具体的设计偏好。

---

## 输入规范

1) 标准输入（$ARGUMENTS）
- 形如：`</path/to/json/file>:<json_path_1>;<json_path_2>;...`
- 说明：
  - `</path/to/json/file>` 为工作区内相对路径；
  - 多个 JSONPath 支持以分号 `;` 分隔；
  - `*`表达省略信息，如`*.lines.pts.pt`，就省略了`lines`之前的信息。
  - 保持输入顺序并去重。

2) 可选补充输入
- 若另行提供“待分析 JSON path（逗号分隔）”，与 $ARGUMENTS 中解析出的路径合并、去重并保持原有顺序。

3) JSONPath 约定
- 基本形式支持：`a.b.c`、`a[0].b`、`a[*].id`；
- 不强制完整 JSONPath 语法，允许常见简写；无法解析时需报告最相近的可行形式。

---

## 执行步骤

1) 读取与解析
- 从工作区读取 `</path/to/json/file>` 并解析为 JSON。
- 若文件过大，可仅截取片段进行分析（如前/中/后各若干 KB），需标注采样策略与文件大小概况。
- 解析失败时，报告错误类型、行列号（若可用）以及错误位置前后约 80 个字符的上下文。

2) 数据链与分组判断
- 按解析得到的 JSONPath 逐一提取节点：
  - 节点缺失、类型不符或索引越界时，标注具体路径与原因，但继续分析其他路径；
  - 为便于理解，可在不显著增加成本的前提下，适度扩展上下文（如父级键、兄弟键、样本统计）。
- 判断合理的分组维度（如：按实体 ID、按时间/步数、按类别、按层级）；
- 识别常见关键字段：主键/ID、时间戳/步数、索引/排序键、数组长度与计数。

3) 程序架构建议（Python）
- 给出从JSON读取数据后的python类建议方案，包括但不限于：
  - 模块拆分与职责；
  - 数据类/实体类设计（字段类型、来源 JSONPath、含义说明）；
  - 读取接口与查询方法（如 get_xxx、iter_xxx、索引构建）；
  - 性能策略（流式/分块、延迟加载、缓存、抽样）与内存取舍；
  - 错误与异常处理（健壮的路径检查、类型校验、日志与告警）。

4) 输出结果
- 整体摘要：对指定数据与其组织结构进行简要说明；
- 建议的数据结构：给出一个或多个 Python 类（或 dataclass）的字段设计与对应 JSONPath 映射，并说明分组/索引策略；
- 给出精简的类与读取骨架代码片段, 写入`temp/*.py`下。

1) 收尾提问
- 询问我的偏好与需求，例如：
  - 类名/文件名命名偏好；
  - 优先关注的字段或路径；
  - 性能与内存的取舍（一次性加载 vs. 流式/分页）；
  - 是否需要并发解析、指标统计或数据校验；
  - 是否需要生成单元测试样例。

---

## 错误处理

- JSON 解析失败：报告错误类型、行列号（若可用）与首个错误位置附近上下文；如可能，建议定位到最外层不匹配的括号或逗号。
- 路径不存在/类型不匹配/索引越界：逐一列出问题路径与原因（缺失/类型期望与实际/下标范围），但不中断其他路径分析。
- 超大节点：仅对片段抽样（如前 N 项、中间若干项、末尾若干项），并输出统计（总数/唯一键计数/示例值），避免展开过长内容。
- 非法 JSONPath：说明无法解析的原因，并给出最相近的可行写法示例。

---

## 输出格式要求

- 使用清晰的小节标题（整体摘要 / 建议的数据结构 / 架构建议 / 错误与告警 / 后续确认）。
- 对字段与路径用列表或简表结构化呈现；长文本超出阈值以省略号折叠。
- 路径按输入顺序呈现，不随意省略；在“为提升速度可适度增加数据”的前提下，明确标注新增的上下文或统计。

---

## 示例

- $ARGUMENTS 示例：
  - `data/sample.json:root.items[*].id;root.items[*].metrics.score*root.summary.total`
- 解析结果：
  - 文件：`data/sample.json`
  - 路径列表（按序去重）：`root.items[*].id`，`root.items[*].metrics.score`，`*.summary.total`
