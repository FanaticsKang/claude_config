# use matplot to show the data in vcs

## 1. 坐标系定义
## 坐标系定义 (Coordinate System Definition)
  - **原点**: 自车中心(+) (0, 0)
  - **X轴**: 纵向，向前为正 (↑)
  - **Y轴**: 横向，向左为正 (←)
  - **重要**:
  只通过matplotlib坐标轴设置实现方向，不要对原始数据取负

  2. Add Visual Reference

  ## 坐标系图示
              ↑ X+ (前)
              |
              |
  ← Y+ (左) --+-- → Y- (右)
              |
              |
              ↓ X- (后)

## 2. 使用matplot绘制vcs传感器信息的基本原则

使用matplot绘制一下数据，这里的数据表达了车体坐标系下车辆周围的传感器信息。
但是要注意以下几点
1. 自车位于位于(0,0)点上；
2. 绘制过程中的横轴和纵轴的比例是相同的；
3. 纵轴为x轴，横轴为y轴，注意这点和原本matplot是不同的；
4. 注意只改变坐标轴方向即可，不要对y轴信息取负；
5. 纵轴向上（↑）为正；
6. 横轴向左（←）为正，注意，这和原本的matplot的默认是相反的。
7. 以坐标（2,0）为中心，绘制一个空心黑色边框的矩形，边线适当加粗表示自车位置，该矩形纵向长5米，横向长2米。 



## 3. 常见错误避免
  1. ❌ 错误: 对Y坐标取负值
     ✅ 正确: 只通过坐标轴方向设置实现左正

  2. ❌ 错误: 箭头方向标注错误
     ✅ 正确: X轴标签使用↑，Y轴标签使用←

  3. ❌ 错误: 坐标轴范围设置顺序错误
     ✅ 正确: ax.set_xlim(y_range[1], y_range[0])
