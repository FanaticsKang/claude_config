# 规范标准合规性审查 Checklist

> 依据：GB/T 20001.5—2017《标准编写规则 第5部分：规范标准》（主）
> 　　　GB/T 20001.1—2024《标准起草规则 第1部分：术语》（术语章节适用）
>
> 使用说明：
> - ✅ 符合　❌ 不符合　⚠️ 需关注／部分符合　N/A 不适用
> - 每条发现问题时，注明所在章条号及具体描述

---

## 模块 A：标准名称（GB/T 20001.5 第6.1条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| A1 | 标准名称是否包含词语"规范"，以表明标准类型 | | |
| A2 | 标准中若仅含"要求"和"证实方法"（或同时含其他非全部基本方面），"规范"是否置于补充要素中 | | |
| A3 | 若适用于一类或多种产品，名称是否包含"通用""总"等限定词 | | |
| A4 | 若仅针对一个或两个标准化目的，名称中是否含描述该目的的词语 | | |
| A5 | 若含三个及以上标准化目的，是否使用"技术规范"而非"技术条件" | | |
| A6 | 英文译名中"规范"是否对应译为"specification" | | |

---

## 模块 B：范围（GB/T 20001.5 第6.2条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| B1 | 范围是否对主要技术内容做出提要式说明 | | |
| B2 | 范围是否指明规定的要求种类及证实方法 | | |
| B3 | 典型表述形式是否为："本标准（部分）规定了……的……要求/通用要求，描述了对应的证实方法，……" | | |
| B4 | 表述"要求"时是否使用词语"规定"；表述"证实方法"时是否使用词语"描述" | | |
| B5 | 范围是否未出现技术要求内容（范围仅作介绍，不作规定） | | |

---

## 模块 C：结构完整性（GB/T 20001.5 第5条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| C1 | 必备要素是否齐全：封面、前言、标准名称、范围、要求、证实方法 | | |
| C2 | 规范性一般要素（规范性引用文件、术语和定义等）是否按序编排 | | |
| C3 | 要素的前后顺序是否符合表1的典型编排 | | |
| C4 | 附录是否区分规范性附录与资料性附录，并在目次和附录标题处标注 | | |
| C5 | 参考文献（如有）是否置于所有附录之后 | | |

---

## 模块 D：总体原则符合性（GB/T 20001.5 第4条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| D1 | **目的导向原则**：标准化目的是否明确？标准化特性或内容的选取是否服务于该目的 | | |
| D2 | **性能/效能原则**：要求是否尽量由反映性能/效能的具体特性来表述，而非设计特性或描述特性 | | |
| D3 | **可证实性原则**：每项要求是否都能在较短时间内得到证实？是否避免了无法证实的定性表述 | | |
| D4 | 是否避免使用"足够坚固""适当的强度""相对完善"等无法证实的表述形式 | | |

## 模块 E：要求的内容（GB/T 20001.5 第6.3条）

### E1 通用要求

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| E1-1 | "要求"是否通过直接或引用方式规定了产品/过程/服务适用性的所有特性 | | |
| E1-2 | "要求"是否规定了特性值 | | |
| E1-3 | "要求"是否适宜时描述了证实方法 | | |

### E2 产品规范标准（如适用）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| E2-1 | 产品要求是否遵守性能原则，由反映产品性能的具体特性表述，不对设计特性规定要求 | | |
| E2-2 | 使用性能要求：是否优先考虑直接反映使用性能的特性（如洁净率、磨损率、功率等） | | |
| E2-3 | 理化性能要求：产品理化性能对使用十分重要时，是否规定了物理、化学、电磁方面的特性 | | |
| E2-4 | 生物学/病理学/毒理学性能要求（如适用）：是否规定了相应特性 | | |
| E2-5 | 人类工效学性能要求（如适用）：是否规定了人机界面特性 | | |
| E2-6 | 环境适应性要求（如适用）：是否规定了温度、湿度、气压等环境适应特性 | | |
| E2-7 | 产品规范标准通常是否未对产品结构规定要求（除非互换性、兼容性或安全需要）| | |
| E2-8 | 产品规范标准通常是否未对材料规定要求（除非保证性能和安全需要）| | |
| E2-9 | 产品规范标准通常是否未对生产过程、工艺规定要求（除非保证性能和安全不得不限定）| | |

### E3 过程规范标准（如适用）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| E3-1 | 是否遵守效能原则，由反映过程效能的具体特性及特性值来表述要求，而非履行过程的具体行为指示 | | |
| E3-2 | 当无法确定反映过程效能的特性时，是否对影响过程效能实现的活动内容或关键程序、步骤等规定了要求 | | |
| E3-3 | 当过程运作的控制条件十分重要时，是否规定了与控制条件有关的特性（如温度、湿度等） | | |

### E4 服务规范标准（如适用）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| E4-1 | 是否遵守效能原则，由反映服务效能的具体特性表述要求，未对组织机构、人员资质等规定要求（特殊情况除外） | | |
| E4-2 | 是否首先规定服务提供者与服务对象接触界面的要求 | | |
| E4-3 | 服务效果、宜人性、响应性、普适性等方面的要求是否按需规定 | | |

## 模块 F：要求的表述（GB/T 20001.5 第6.3.5条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| F1 | "要求"是否全部以要求型条款表述（不出现陈述性语句作为要求） | | |
| F2 | 要求型条款是否使用以下典型句式之一： | | |
| | ——"特性"按"证实方法"试验"应"符合"特性值"的规定 | | |
| | ——"特性"按"证实方法"试验"应"大于／小于"特性值" | | |
| | ——按"证实方法"试验，"特性""应"大于／小于"特性值" | | |
| | ——"特性""应"保证／达到"特性值"的规定 | | |
| | ——"谁""应""怎么做" | | |
| F3 | 是否避免使用"足够坚固""适当的强度""相对完善"等无法证实的表述 | | |
| F4 | 适宜时，要求型条款是否用表格表述（表头含编号、特性、特性值、证实方法） | | |
| F5 | 表格在正文中是否以6.3.5.1中的典型句式提及 | | |
| F6 | 要求中是否存在"应避免""禁止使用""不宜"等条件型限制条款，并是否使用了正确的助动词 | | |
| F7 | 适宜时，要求型条款是否使用表格形式，表格行含：条号、特性、特性值、证实方法 | | |

## 模块 G：证实方法（GB/T 20001.5 第6.4条）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| G1 | 针对"要求"中的每项要求，是否都描述了对应的证实方法 | | |
| G2 | 证实方法是否为以下之一：测量和试验方法；信息化方法；主观评价等其他证实方法 | | |
| G3 | 产品规范标准是否主要考虑测量和试验方法（证实方法a类） | | |
| G4 | 过程和服务规范标准是否主要考虑信息化或主观评价方法（证实方法b、c类） | | |
| G5 | 证实方法是否按照与"要求"相对应的先后顺序编写 | | |
| G6 | 若存在现行适用的标准，是否引用了这些标准（而非重复描述） | | |
| G7 | 若存在多种适用的证实方法，是否只描述了一种（特殊情况除外，需指明仲裁方法） | | |
| G8 | **测量和试验方法**：是否包含测量/试验步骤以及数据处理（含计算方法、结果表述） | | |
| G9 | **测量和试验方法**：是否规定了试样/样品要求（如形状、尺寸）、仪器设备、技术条件、环境条件等必要内容 | | |
| G10 | **信息化方法及主观评价等**：是否描述了实施主体、实施频率或持续时间、起始时间、扫描上传、观察、记录、确认/评价内容以及计算方法 | | |
| G11 | 测量/试验步骤、数据处理等内容是否符合 GB/T 20001.4 的有关规则 | | |
| G12 | 证实方法中的检验和试验方法，是否规定了适用的样品数量、条件（含制备条件、储存条件）、测试程序及步骤、必要的校准方法等 | | |

## 模块 H：术语和定义章节（GB/T 20001.1—2024 第10、13章）

> 此模块适用于标准中含有"术语和定义"章节的情况

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| H1 | 术语章节是否只定义本标准所用的术语，以及有助于理解这些术语的相关术语（第13.1条） | | |
| H2 | 是否避免定义与本标准范围无关的术语（第4条b款） | | |
| H3 | 概念是否与已发布的国家标准、行业标准中确定的概念保持协调，避免矛盾（第4条c款）| | |
| H4 | 是否已对引用其他标准中术语的情况按规定写明来源（第10.5.6.1条） | | |
| H5 | 术语条目编号是否唯一，格式是否符合要求（黑体、五号、顶格排） | | |
| H6 | **首选术语**：格式是否为黑体、五号，置于条目编号后另起一行空两个汉字排 | | |
| H7 | **英文对应词**：是否空一个汉字排在汉语首选术语之后（若有） | | |
| H8 | **许用术语**（如有）：格式是否为宋体、五号，置于首选术语之后 | | |
| H9 | **拒用术语**（如有）：格式是否为宋体、五号，并在圆括号中标示"拒用" | | |
| H10 | **定义**：是否采用陈述的形式，置于对应词之后，另起一行空两汉字排（宋体、五号） | | |
| H11 | **定义内容**：是否涵盖一般或常见语境中术语的使用，符合相关领域专业一般认识（第10.5.2条） | | |
| H12 | 定义是否满足替代原则：定义能在语境中替代对应术语而不导致意义改变或丢失 | | |
| H13 | 定义是否避免使用"用于描述……的术语""表示……的术语"等说明性形式 | | |
| H14 | 定义是否避免以"这个""该""一个"等指代性词语开头（第10.5.5条c款）| | |
| H15 | 定义中引用本标准已定义的其他首选术语时，是否在该术语后圆括号中给出对应条目编号（第10.5.7条）| | |
| H16 | 如涉及同形异义词，是否用不同术语条目定义，并用"参见："指出 | | |
| H17 | 术语条目是否按系统顺序或混合顺序排列（第7.6条）；若为混合顺序，是否按汉语拼音排序 | | |
| H18 | 非术语标准中，术语条目是否按 GB/T 1.1—2020 第8.7.3.1条规定或正文中术语首次出现顺序排列（第13.3条） | | |

## 模块 I：规范性引用文件（适用时）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| I1 | 规范性引用文件是否仅列入标准正文中规范性引用的文件（不含资料性引用） | | |
| I2 | 注日期的引用文件（仅该版本适用）是否标注了日期 | | |
| I3 | 不注日期的引用文件（最新版本适用）是否未标注日期 | | |
| I4 | 引用文件是否按照 GB/T 1.1 的规定格式著录 | | |

## 模块 J：附录（适用时）

| # | 核查要点 | 结果 | 问题描述 |
|---|---------|------|---------|
| J1 | 附录是否在正文中被提及 | | |
| J2 | 每个附录是否标注了其性质（规范性附录／资料性附录） | | |
| J3 | 规范性附录中是否未出现资料性内容；资料性附录中是否未出现规范性要求 | | |
